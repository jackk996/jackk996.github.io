# Repository Audit

Audit date: 2026-06-29.

## Scope

The repository was scanned for raw/processed risk data, indicator definitions, longitudinal identifiers, model code, notebooks, configuration, and experiment results related to the paper "基于多源数据融合的软件信息化项目风险智能预警与动态管控研究".

## Findings

- No raw or processed project-risk dataset was found under the repository root.
- No table containing the required composite key `project_id`, `subsystem_id`, and `month` was found.
- No monthly ground-truth `risk_score` field was found.
- No existing implementation of the 20 paper risk indicators was found.
- Existing Python and notebook files are for publication/talk generation and map generation, not the requested TensorFlow risk-warning experiments.
- No existing trained models, checkpoints, risk metrics, experiment tables, or risk explanations for this study were found.

## Consequence

The codebase can implement and test the reproducible pipeline, but paper numerical reproduction cannot be verified until the real monthly subsystem-level data is supplied. Synthetic data generated by this project is only for unit tests and pipeline demonstration and must be labelled `synthetic_demo`.
